# 画像比較ツール仕様書

## 目的

現行システムと更改システムや、バージョン修正後の表示内容について差分を確認するため、保存されたスクリーンショットを比較して差分を検出する。

## 機能概要

1. **比較対象のディレクトリ選択**
    - ローカルに存在する2つのディレクトリを選択するウィンドウを表示する。
    - ユーザーがディレクトリを選択後、後続の処理でその値を利用して処理を行う。

2. **画像比較**
    - [1. 比較対象のディレクトリ選択]で取得した二つのディレクトリ内に存在する画像ファイルの比較を行い、差分を検出する。
    - 差分を検出する際には、以下のいずれかの方法をユーザーが実行時に選択できるようにする。
      - ピクセル単位の比較
      - 画像ヒストグラム比較
      - SSIM（Structural Similarity Index）
      - OpenCVを利用した画像比較
      - その他の適切な手法
    - 差分が検出された場合は、差分画像を生成する。

3. **比較結果のレポート出力**
    - 差分検出した結果をレポートとして出力する。
    - レポートの内容は以下の通り:
      - **サマリーレポート**
        - 比較した画像の一覧
        - 差分が検出された画像の数
        - 一致した画像の数
      - **差分比較画像**
        - 差分が強調された画像の出力
        - 差分の割合やヒートマップ表示などのオプション提供
    - レポートの出力形式はHTML形式

## システム構成とインターフェース

### **システム構成**

```
+-------------------------+
| GUI (tkinter)          |
| - ディレクトリ選択      |
| - 比較手法の選択        |
+-------------------------+
          |
          v
+-------------------------+
| 画像処理エンジン        |
| - OpenCV, numpy        |
| - 画像差分検出          |
+-------------------------+
          |
          v
+-------------------------+
| レポート生成モジュール   |
| - pandas, matplotlib   |
| - HTML形式での出力      |
+-------------------------+
```

### **モジュール間のインターフェース**

1. **GUI → 画像処理エンジン**
    - `selected_dir_1`: 比較対象ディレクトリ1のパス
    - `selected_dir_2`: 比較対象ディレクトリ2のパス
    - `comparison_method`: ユーザーが選択した比較方法（ピクセル単位、SSIMなど）

2. **画像処理エンジン → レポート生成モジュール**
    - `comparison_results`: 差分比較結果のデータ構造（画像リスト、差分情報）

3. **レポート生成モジュール → 出力**
    - `output.html`: HTML形式のレポート
    - `difference_images/`: 差分画像を保存するディレクトリ

## 環境概要

- **使用言語**: Python 3.12
- **使用ライブラリ（予定）**:
  - `tkinter`（GUIのディレクトリ選択）
  - `opencv-python`（画像処理）
  - `numpy`（配列計算）
  - `scipy`（画像比較: SSIM）
  - `pandas`（レポート生成）
  - `matplotlib`（差分画像の可視化）

## 環境構築手順

1. **Pythonのインストール**
    - [Python公式サイト](https://www.python.org/)からPython 3.12をダウンロードし、インストールする。
    - インストール後、以下のコマンドでバージョンを確認する。

      ```sh
      python --version
      ```

2. **仮想環境の作成**
    - Pythonの仮想環境を作成し、依存関係を分離する。

      ```sh
      python -m venv diffTool
      ```

    - 作成した仮想環境を有効化する。
      - Windows:

        ```sh
        venv\Scripts\activate
        ```

      - macOS/Linux:

        ```sh
        source diffTool/bin/activate
        ```

3. **必要なライブラリのインストール**
    - `requirements.txt`を作成し、以下の内容を記述する。

      ```
      opencv-python
      numpy
      scipy
      pandas
      matplotlib
      ```

    - ライブラリをインストールする。

      ```sh
      pip install -r requirements.txt
      ```

4. **依存関係の確認**
    - 正しくインストールされているか確認する。

      ```sh
      pip list
      ```

5. **動作確認**
    - `python`を起動し、以下のコマンドを実行して各ライブラリがインポートできることを確認する。

      ```python
      import cv2
      import numpy as np
      import scipy
      import pandas as pd
      import matplotlib.pyplot as plt
      ```

    - エラーが出なければ環境構築完了。

## 実装方針

1. **GUIの作成**
    - `tkinter` を使用してディレクトリ選択用のGUIを作成する。
    - ユーザーが選択したディレクトリのパスを取得し、後続処理に渡す。

2. **画像ファイルの取得とペアリング**
    - 指定された2つのディレクトリ内の画像ファイルをリストアップする。
    - 同じ名前の画像ファイルをペアリングし、比較対象とする。

3. **画像の差分比較**
    - OpenCVを使用して画像を読み込み、差分を計算する。
    - ピクセル単位、SSIMなど複数の手法を実装し、ユーザーが実行時に選択できるようにする。

4. **比較結果の保存と出力**
    - 差分がある画像をハイライトした画像を生成する。
    - 結果をHTMLレポートとして出力する。

## 追加機能（今後の拡張）

- **バッチ処理対応**: 大量の画像を自動処理できるようにする。
- **しきい値設定**: 差分の度合いに応じて閾値を設定し、微小な差分を無視できるようにする。
- **クラウドストレージ連携**: Google DriveやAWS S3などのクラウドストレージから画像を取得・比較できるようにする。
